# Emblem Studio MCP server

Build popups and opt-in forms on your website from Claude or any MCP client. Lead capture with A/B testing, stats, surveys and scheduling.

**Server address:** `https://emblemstudio.ai/mcp/strategist`

Sign in with your Emblem Studio account (OAuth).

This repository holds documentation only. Emblem Studio hosts the server, and its code is not here.

## What your AI can do

- Read views, sign-ups, conversion rates and survey answers
- Build and edit popups, opt-in forms, ribbons and slide-ins
- Start and end A/B tests
- Schedule when each one shows

New popups and forms start switched off, so nothing reaches a visitor until you say so.

## Connect

**Claude:** add [Emblem Studio from the connector directory](https://claude.ai/directory/connectors/emblem-studio).

**Claude Code:**

```
claude mcp add --transport http emblem-studio https://emblemstudio.ai/mcp/strategist
```

**Another AI app:** add a remote MCP server (it may be called "streamable HTTP") with the address above.
